# 🔢 2048 (Sliding Block Math Classic)

An authentic recreation of the classic 2048 number sliding puzzle with smooth touch gestures, undo support, high-score tracking, and full offline PWA support.

---

## 🎮 How to Play

- **Web Browser**:
  - Visit `http://localhost:8080/2048/`
  - Use **Arrow Keys / WASD** or swipe on touchscreens.
- **Terminal CLI**:
  ```bash
  python3 /mnt/sharedroot/projects/games/2048/cli/game2048_cli.py
  ```
