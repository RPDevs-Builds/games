# 💣 Minesweeper (Windows 95 Classic)

An authentic recreation of the classic Windows 95/98 Minesweeper with beveled grey styling, classic smiley button, guaranteed first-click safety, and full offline PWA support.

---

## 🎮 How to Play

- **Web Browser**:
  - Visit `http://localhost:8080/minesweeper/`
  - Left-click to reveal.
  - Right-click (or toggle the Flag button on mobile) to plant a flag 🚩.
  - Click the 🙂 face to start a new game.
- **Terminal CLI**:
  ```bash
  python3 /mnt/sharedroot/projects/games/minesweeper/cli/minesweeper_cli.py
  ```
