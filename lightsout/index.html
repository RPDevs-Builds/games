📖 Rules & Light Chasing Strategy

The Objective

Turn ALL lights OFF in the fewest moves possible.

The Toggle Rule

Pressing any light toggles its state (ON $\leftrightarrow$ OFF) and also flips all 4 directly adjacent (orthogonal) neighbors (Up, Down, Left, Right).

Golden Rules of Lights Out

  • Order Does Not Matter: Pressing A then B gives the exact same result as B then A.
  • Never Press Twice: Pressing a button twice returns it to its starting state ($1 \oplus 1 = 0$). An optimal solution only presses any button at most once.

The "Light Chasing" Strategy

  1. Work top to bottom! For every light ON in Row 1, press the button directly below it in Row 2. Row 1 is now dark!
  2. For every light ON in Row 2, press the button below it in Row 3.
  3. Repeat for Rows 3 and 4. Now only lights in Row 5 remain.
  4. If Row 5 is solved, you won! Otherwise, press the corresponding buttons in Row 1 using the 7 known Tiger patterns and chase down again.

Mathematical Engine

This implementation features a complete $GF(2)$ Gaussian Elimination solver. The 5×5 toggle matrix has rank 23 and a 2D null space, meaning exactly 25% of random boards are solvable. All puzzles generated here are mathematically guaranteed solvable!
