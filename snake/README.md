# 🐍 Retro Snake (Nokia 3310 Edition)

An authentic recreation of the legendary Nokia 3310 green LCD monochrome Snake game.
Built with zero external dependencies (HTML5 Canvas + Web Audio API) with full PWA offline support and an interactive terminal CLI port.

---

## 🎮 How to Play

- **Web Browser**:
  - Visit `http://localhost:8080/snake/`
  - Steer with Arrow Keys, `W`, `A`, `S`, `D`, or touch the on-screen keypad.
  - Eat food pellets to score points and grow. Avoid walls and yourself!
- **Terminal CLI**:
  ```bash
  python3 /mnt/sharedroot/projects/games/snake/cli/snake_cli.py
  ```
