# 🔴🟢 Simon (1978 Handheld Memory Classic)

An authentic recreation of the 1978 Milton Bradley Simon handheld electronic memory game.
Features exact historical harmonic frequencies, progressive speed ramping, strict mode, and full offline PWA support.

---

## 🎮 How to Play

- **Web Browser**:
  - Visit `http://localhost:8080/simon/`
  - Click or tap the illuminated colored quadrants, or use keys `Q` (Green), `W` (Red), `A` (Yellow), `S` (Blue).
- **Terminal CLI**:
  ```bash
  python3 /mnt/sharedroot/projects/games/simon/cli/simon_cli.py
  ```
